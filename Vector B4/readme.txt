
"Создать код сканирования"
	- создает файл scaner.tap, который используется для сканирования (определения геометрии) диска;
"Конвертировать облако точек"
	- читает файл "oblako T.tap" (полученый после сканирования диска) и создает из него файл "LINE.dxf", представляющий контур диска;
"Исправить возврат и добавить повторы"
	- изменяет в файле G-Code.tap (из программы ArtCAM, по файлу dxf) операцию возврата резца, так, чтобы он не задевал диск, также делает несколько повторов со смещением (несколько слоев среза).

Описание формата .tap файла:
https://en.wikipedia.org/wiki/G-code

Для визуализации можно использовать например jViewer http://www.thingiverse.com/thing:72324

T		Tool selection
M		Miscellaneous (M00 - Compulsory stop, M3 - Spindle On, M5 - Spindle Off, M30 - End of Program)
G		Address for preparatory commands (G0 - Rapid Positioning - максимально быстрое перемещение в позицию (обычно для подвода инструмента к началу обработки или отхода от заготовки), может быть нелинейной (т.е. одна из осей может быстрей закончить движение), G1 - перемещение по прямой линии в рабочем режиме)
F		Feed Rate
S		Speed
X,Y,Z	Coordinates

Действие большинства G-кодов сохраняется, например:
G1 X74.904 Y230.928 F240.0
X45.400 Y239.700
X42.000 Y232.100
для второй и третей строки будет использовать G1 и F240
